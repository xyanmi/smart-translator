Google翻译设置

Google翻译使用公共API，无需设置API密钥。

Bing翻译设置

如何获取Bing翻译API密钥:

  1. 访问 Microsoft Translator API
  2. 注册或登录Microsoft Azure账号
  3. 创建一个Translator资源
  4. 在资源管理页面获取API密钥

DeepL翻译设置

如何获取DeepL API密钥:

  1. 访问 DeepL API
  2. 注册或登录DeepL账号
  3. 选择API计划（有免费选项）
  4. 在账户设置中获取API密钥

OpenRouter 设置

如何获取OpenRouter API密钥:

  1. 访问 OpenRouter Platform
  2. 注册或登录OpenRouter账号
  3. 在个人设置中创建API密钥

DeepSeek翻译设置

如何获取DeepSeek API密钥:

  1. 访问 DeepSeek Platform
  2. 注册或登录DeepSeek账号
  3. 在账户设置中创建API密钥

Gemini翻译设置

如何获取Gemini API密钥:

  1. 访问 Google AI Studio
  2. 使用Google账号登录
  3. 创建新的API密钥
